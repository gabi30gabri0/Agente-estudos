Documentação do Projeto – Chat com IA

1. Sobre o projeto

Este projeto é um sistema de chat com inteligência artificial, desenvolvido em PHP, HTML e JavaScript, integrado ao Supabase e à API do Google Gemini.

2. Tecnologias utilizadas

* PHP
* HTML5
* CSS3
* JavaScript
* Supabase
* Google Gemini API

3. Funcionalidades

* Conversas com inteligência artificial.
* Integração com Google Gemini.
* Histórico de conversas.
* Gerenciamento das conversas.
* Armazenamento de informações no Supabase.

4. Configuração do Supabase

URL do projeto Supabase:

https://srdxkabotylgrgfdgkjy.supabase.co

Configure o endereço do projeto e as credenciais necessárias no arquivo de configuração da aplicação.

Não compartilhe chaves privadas ou credenciais administrativas publicamente.

5. Configuração do Google Gemini

Para utilizar a inteligência artificial, é necessário configurar uma chave de API do Google Gemini.

A chave deve ser armazenada em local seguro, preferencialmente no servidor, e não diretamente no JavaScript do navegador.

6. Estrutura do projeto

Os principais arquivos incluem:

* index.php – Página principal do sistema.
* .env.php – Configurações da aplicação.
* README.md – Documentação do projeto.

7. Instalação

1. Baixe ou clone os arquivos do projeto.
2. Configure o ambiente PHP.
3. Configure as credenciais do Supabase.
4. Configure a chave da API do Google Gemini.
5. Execute os scripts SQL necessários no Supabase, caso existam.
6. Inicie o servidor PHP.
7. Acesse o sistema pelo navegador.

8. Banco de dados

O Supabase é utilizado para armazenar as informações do sistema e o histórico de conversas.

As tabelas e políticas de segurança devem estar configuradas no painel do Supabase.

9. Segurança

* Não publique chaves privadas.
* Utilize variáveis de ambiente para armazenar credenciais.
* Mantenha as políticas RLS ativadas quando aplicáveis.
* Valide as informações recebidas pelo servidor.
* Proteja os dados armazenados.

10. Considerações finais

Este projeto foi desenvolvido para oferecer uma experiência de conversa com inteligência artificial, utilizando o Google Gemini e o Supabase para integração e armazenamento de informações.
